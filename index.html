  • 慢跑：约8-10km/h，步频180左右小步快跑，不追求速度

科普 · 为什么“微喘能说话”

你的最大心率约 220-21 = 199 次/分。中等强度 = 最大心率的 60-70%，即约 120-140 次/分——这正是脂肪供能比例最高的区间：强度太低烧得少，强度太高（喘到说不出话）主要烧糖原、坚持不了几分钟。所以“微喘能说话”不是感觉，是精确到数字的强度刻度。

休息日 · 周三 / 周五 / 周日

晚饭后散步 20分钟 + 全身拉伸 10分钟。休息不是躺平：散步维持活动量、拉伸加速恢复，而肌肉正是在休息日修复变强的。考研复习间隙每40-50分钟起身走2分钟。

注意：膝盖不舒服就把深蹲改半蹲、跳绳改快走；力量训练后第二三天肌肉酸痛是正常的（延迟性酸痛），酸痛期照常有氧，动作幅度可以减小但别停；21:30 前结束运动，否则影响睡眠。

科普 · 为什么蛋白质是减脂期第一营养素

① 保肌肉：热量缺口下身体会拆肌肉当燃料，蛋白质吃够（减脂期建议约1.6-2.2g/kg，你93kg对应约150-200g）能按住房东——肌肉少了，基础代谢就跟着降，越减越难减。
② 食物热效应：消化蛋白质本身就要消耗其约25%的热量（碳水约5-10%、脂肪约0-3%），同样吃一顿，高蛋白餐实际“到手”的热量更少。
③ 扛饿：蛋白质的饱腹感是碳水的两倍以上，是“饿到破功”的天敌。

科普 · 为什么“油大过水”能省这么多

1g 脂肪 = 9千卡，1g 蛋白质/碳水 = 4千卡。食堂一份红烧菜盘底那层油看着不多，其实常有 15-30g——那就是 135-270千卡，比你少吃半碗饭还狠。涮一下水，等于直接把菜里最不划算的那部分热量倒掉。菜汤同理：油、盐、嘌呤全溶在汤里，汤是食堂菜里热量密度最高的部分之一。

减脂原理 · 这套方案为什么这么设计

先懂原理，再谈执行。每一节都是“科普机制 + 你的落地”两件事。

1. 热量缺口：减脂唯一的原理 必读

减脂的本质是能量守恒：摄入 < 消耗，身体就拿脂肪补差额。1kg 脂肪组织 ≈ 7700千卡（约1斤≈3850千卡）。每天 -500千卡，一周约 -3500千卡 ≈ 每周减 1 斤左右——这就是“每周0.5kg”的数学来源。

你的落地：缺口从三处来——① 停掉面包，每天省约771千卡；② 晚餐去肠，省150-200千卡；③ 运动4次/周，每次约200-300千卡。合计每天约 -500~700千卡，正落在健康减脂区间（每周0.4-0.7kg），既不会饿到崩，也不会掉太快伤代谢。

2. 你的身体先烧多少：代谢基数

用标准公式（Mifflin-St Jeor）估算你的基础代谢：10×93kg + 6.25×185cm − 5×21岁 + 5 ≈ 1990千卡/天——这是你躺着不动也要烧的。加上久坐备考的活动量（乘1.2-1.4），维持热量约 2400-2700千卡/天。
但比公式更准的是你自己的历史数据：你“不吃早饭”时体重稳定在185斤，说明当时的总摄入 ≈ 你的实际消耗——这就是你的个人校准值，公式仅供参考。

你的落地：所以方案的主战场不是“继续狠饿”，而是别在稳定平衡上再加771千卡。恢复原饮食 = 回到平衡，再叠加运动 = 进入温和缺口。饿过头反而会把基础代谢也饿下来，越减越难。

3. 蛋白质：减脂期第一营养素

热量缺口下身体会拆肌肉供能，蛋白质吃够能“保住肌肉”：减脂期推荐约 1.6-2.2g/kg（你93kg对应150-200g）。肌肉是基础代谢的发动机，肌肉掉一公斤，每天少烧约十几千卡，日积月累就是反弹的伏笔。另外蛋白质的食物热效应高达约25%，消化它本身就在烧热量。

你的落地：目标140-160g/天，用“蛋+鸡腿+奶+豆”凑（凑法见饮食页表格），下午饿时优先补蛋/奶。这是四项打卡里唯一和“吃”有关的关键项。

4. 碳水不是敌人

大脑几乎只烧葡萄糖，米饭、玉米这些碳水是备考状态的燃料。真正的问题是过量精制碳水（白粥、甜面包）让血糖坐过山车。而且——你正在治斑秃，极低碳水已被观察到与脱发加重相关，这绝对不是你该走的路线。

你的落地：主食保留：米饭1-1.5拳，可替换玉米/红薯（慢碳水，血糖更平缓）。砍碳水不是目标，砍“多余的精制碳水+脂肪”才是。

5. 体重秤会骗人：水分 vs 脂肪

身体的水分波动 ±1-2斤是常态：盐吃多了水潴留、糖原储备变化（1g糖原携带约3-4g水）、女性生理周期（与本次无关）都会让体重一天内跳动。你还有第三个变量——复方甘草酸苷片可能引起水钠潴留（见第9节）。所以单日体重毫无意义，趋势才可信。

你的落地：只认每周一早晨空腹体重 + 腰围（肚脐水平）。腰围比体重秤可信——它不掺水。

6. 睡眠是隐形杠杆

睡不足时，瘦素（抑制食欲）下降、饥饿素（促进食欲）上升、皮质醇升高——第二天不仅更饿，还更想吃高热量食物。这不是意志力问题，是激素在替你做决定。你的睡眠周期约90分钟，23:40-7:40 ≈ 5个完整周期。

你的落地：23:40前放下手机，睡满约7.5小时；午休30-60分钟且不超过1小时。把睡眠当减脂任务的一项，不是可有可无的奢侈。

7. 平台期：身体在重新校准

减脂4-8周后常见体重停滞：一是代谢适应（体重下降后消耗也降一点，缺口自动收窄），二是水分再平衡——这不代表脂肪没在减。围度和照片比体重更诚实，平台期通常是“身体在调整”，不是“计划失效”。

你的落地：平台期保持执行、只量腰围，别靠更狠的节食硬突破；两周反馈机制就是为了在这种时候做微调而不是瞎折腾。

8. 为什么有氧 + 力量都要做

有氧（周二/六）直接烧热量、练心肺；力量（周一/四）不追求“练哪瘦哪”，而是给身体发信号：“肌肉还要用，别拆它”。光有氧不力量，减重快但肌肉流失也快，基础代谢跟着降；两者搭配，掉的是脂肪、保住的是代谢。

你的落地：每周4次：周一/四力量（宿舍自重，60分钟），周二/六有氧或篮球（40分钟）。这就是“4次”的全部理由。

9. 你的药物与体重：先别怪自己

复方甘草酸苷片的活性成分甘草酸会抑制肾脏里的11β-HSD2酶，让皮质醇“假性过剩”，产生类似醛固酮的作用——即说明书列出的“假性醛固酮增多症”：钠和水潴留、浮肿、体重增加、血压升高、低钾。这意味着你体重的部分“虚高”可能是药物造成的，不是你没执行好。地奈德乳膏外用吸收极少，基本不影响减脂。

你的落地：① 腰围、照片、衣服松紧是主要依据，体重数字打折看；② 若明显浮肿、体重不降反升、乏力，去复诊让医生判断，不要自行停药；③ 有条件偶尔量量血压。

用药提醒 · 治斑秃

复方甘草酸苷片说明书明确列出“假性醛固酮增多症”不良反应：钠和液体潴留、浮肿、体重增加、血压升高。

机制：甘草酸抑制肾脏 11β-HSD2 酶 → 皮质醇“假性过剩” → 产生类似醛固酮的保钠保水作用。这是药物本身的作用，不是你的失败。

  • 午休控制在30-60分钟，不超过1小时（睡久会头晕且挤占晚上睡意）
  • 为什么重要：睡眠不足 → 瘦素↓（不觉得饱）、饥饿素↑（总觉得饿）、皮质醇↑（脂肪更易堆在肚子）——三天睡不好，就能抵消你省下的771千卡中相当一部分的食欲收益

监测规则

  • 每周一早晨：空腹、上完厕所后称重 + 量腰围（肚脐水平），记在「记录」页
  • 别天天称：日间 ±1-2斤是水分波动，不是脂肪（原因见「原理」页第5节）
  • 药物引起的水钠潴留可能让体重比真实脂肪更“重”，腰围和衣服松紧才是硬指标

两周反馈 · 每两周周一，把三项发我

  • 早晨空腹体重
  • 腰围（肚脐水平）
  • 执行情况：面包碰没碰、运动几次、睡眠平均几点睡

调整规则（按两周趋势）

  • 掉速正常（约0.5kg/周）→ 维持现状，别画蛇添足
  • 掉太快（连续两周 >1kg/周）→ 午餐/晚餐各加一点主食（米饭加半拳）
  • 几乎不掉 → 先查水分因素（药、盐、睡眠），再考虑午餐压到1拳或每周运动加1次
